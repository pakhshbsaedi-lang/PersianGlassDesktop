# PersianGlass Desktop V2 — سورس بازطراحی‌شده

این نسخه، بازطراحی واقعی پروژه WPF قبلی است؛ نه تصویر یا ماکاپ.

## ساخت در ویندوز ۱۰/۱۱
نیازمند .NET 8 SDK با workload دسکتاپ ویندوز:
```powershell
dotnet restore
dotnet run
```
ساخت نسخه مستقل x64:
```powershell
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

## تغییرات V2
- حذف کامل ScrollViewer و اسکرول؛ نمایش اطلاعات در کارت‌های دو ستونه
- پنجره بدون قاب، بدون حضور در taskbar، جای‌گیری اولیه بالا-راست صفحه
- جابه‌جایی با کشیدن سربرگ، قفل موقعیت و حالت همیشه‌بالا
- تقویم شمسی با شروع هفته از شنبه، هایلایت امروز، جابه‌جایی ماه و بازگشت به امروز
- ساعت ایران و تاریخ‌های شمسی، میلادی و قمری با رقم‌گذاری فارسی
- نمایش دقیق عنوان بازار «طلای ۱۸ عیار، هر گرم»؛ تا زمان اتصال منبع، قیمت ساختگی نشان داده نمی‌شود
- نوار پیشرفت ماه
- گزینه فعال/غیرفعال‌سازی اجرای خودکار ویندوز از تنظیمات

## مواردی که هنوز نیازمند اتصال منبع یا پیاده‌سازی تکمیلی‌اند
آب‌وهوای زنده و AQI/پیش‌بینی ۷ روزه، دلار آزاد، قیمت گرم طلای ۱۸ عیار به تومان، نفت برنت، مناسبت‌های رسمی و تعطیلات، اوقات شرعی، ذخیره یادآورها و کش آفلاین. رابط فعلاً عمداً جای خالی/وضعیت عدم اتصال نشان می‌دهد و هیچ عددی را جعل نمی‌کند.
همچنین حالت واقعی قرارگیری پشت پنجره‌ها در لایه دسکتاپ ویندوز (WorkerW)، نصب‌کننده و تنظیمات پیشرفته شفافیت/ابعاد در این بسته هنوز پیاده‌سازی نشده‌اند. پنجره در حالت عادی بدون taskbar و غیر Always-on-top است؛ دکمه سنجاق حالت Always-on-top را فعال می‌کند.

## حریم خصوصی
هیچ API key یا داده شخصی در پروژه قرار داده نشده است. قیمت‌های بازار تا زمان انتخاب منبع معتبر دریافت نمی‌شوند.
