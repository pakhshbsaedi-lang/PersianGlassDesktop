# PersianGlass Desktop — نسخه نمایشی اولیه

این بسته یک **پروژه منبع WPF برای ویندوز ۱۰** است، نه فایل نصب نهایی و نه نسخه کامل محصول.

## پیش‌نیاز ساخت
- Windows 10
- .NET 8 SDK (با پشتیبانی Windows Desktop)
- Visual Studio 2022 با workload «.NET desktop development» یا `dotnet` CLI

## اجرا
از پوشه پروژه در ترمینال ویندوز اجرا کنید:

```powershell
dotnet restore
dotnet run
```

برای انتشار مستقل:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

فایل خروجی در مسیر `bin\Release\net8.0-windows\win-x64\publish` ساخته می‌شود.

## فونت‌ها
برنامه از فونت‌های نصب‌شده با نام‌های `B Yekan` و `B Titr` استفاده می‌کند. اگر فونت در ویندوز موجود نباشد، WPF از فونت جایگزین استفاده می‌کند. فونت B Nazanin در مرحله تکمیل تایپوگرافی به بخش‌های متنی/مناسبت‌ها افزوده می‌شود.
